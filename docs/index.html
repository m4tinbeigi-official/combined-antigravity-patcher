ویژگی‌های پچ ترکیبی

با این اسکریپت، نیازی به نصب جداگانه و پیچیدهٔ ابزارها ندارید. همه چیز خودکار انجام می‌شود.

با پیاده‌سازی پچ kakajan، مشکل عدم اتصال و خطای پروکسی در زمان احراز هویت به طور کامل رفع می‌شود.

🌍

حذف محدودیت جغرافیایی

پچ AvenCores به صورت محلی بررسی‌های موقعیت مکانی و قفل‌های منطقه‌ای را غیرفعال کرده و برنامه را باز می‌کند.

⚡

پشتیبان‌گیری خودکار

اسکریپت قبل از اعمال هر تغییری، از فایل‌های مهم کپی پشتیبان تهیه می‌کند تا بتوانید به راحتی وضعیت را بازیابی کنید.

راهنمای نصب و اجرا

سیستم‌عامل خود را انتخاب کرده و دستور زیر را در ترمینال یا پاورشل با دسترسی ادمین اجرا کنید.

macOS PowerShell (pwsh) 
# کلون کردن ریپازیتوری پچ ترکیبی
git clone https://github.com/m4tinbeigi-official/combined-antigravity-patcher.git
cd combined-antigravity-patcher

# ۱. اجرای کامل (هر دو پچ ورود و ریجن):
pwsh ./install-antigravity-patch.ps1

# ۲. اجرای اختصاصی پچ ریجن (فقط رفع محدودیت جغرافیایی):
pwsh ./install-antigravity-patch.ps1 -RegionOnly

# ۳. اجرای اختصاصی پچ ورود (فقط رفع خطای Authorization):
pwsh ./install-antigravity-patch.ps1 -AuthOnly
Windows PowerShell (Admin) 
# ابتدا پاورشل را در حالت ادمین (Run as Administrator) باز کرده و دستورات زیر را اجرا کنید:
git clone https://github.com/m4tinbeigi-official/combined-antigravity-patcher.git
cd combined-antigravity-patcher
Set-ExecutionPolicy Bypass -Scope Process -Force

# ۱. اجرای کامل (هر دو پچ ورود و ریجن):
pwsh ./install-antigravity-patch-windows.ps1

# ۲. اجرای اختصاصی پچ ریجن (فقط رفع محدودیت جغرافیایی):
pwsh ./install-antigravity-patch-windows.ps1 -RegionOnly

# ۳. اجرای اختصاصی پچ ورود (فقط رفع خطای Authorization):
pwsh ./install-antigravity-patch-windows.ps1 -AuthOnly

پروژه‌های مرجع و ایده اصلی

این پروژه به طور مستقیم بر پایه تلاش‌ها و نوآوری‌های دو پروژه زیر توسعه داده شده است:

antigravity-patch
طراحی شده توسط kakajan برای رفع مشکل لاگین
open-antigravity-patcher
طراحی شده توسط AvenCores برای بایپس منطقه‌ای

تمامی حقوق و کدهای اصلی متعلق به توسعه‌دهندگان پروژه‌های مرجع می‌باشد.
