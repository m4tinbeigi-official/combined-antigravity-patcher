Installation Guide

Select your operating system and execute the commands below in your Terminal or PowerShell (Admin).

macOS PowerShell (pwsh) 
# Clone repository
git clone https://github.com/m4tinbeigi-official/combined-antigravity-patcher.git
cd combined-antigravity-patcher

# Option 1: Apply BOTH patches (Auth & Region)
pwsh ./install-antigravity-patch.ps1

# Option 2: Apply ONLY the region bypass (for regional restrictions)
pwsh ./install-antigravity-patch.ps1 -RegionOnly

# Option 3: Apply ONLY the authorization/proxy fix
pwsh ./install-antigravity-patch.ps1 -AuthOnly
Windows PowerShell (Admin) 
# Open PowerShell as Administrator, then run:
git clone https://github.com/m4tinbeigi-official/combined-antigravity-patcher.git
cd combined-antigravity-patcher
Set-ExecutionPolicy Bypass -Scope Process -Force

# Option 1: Apply BOTH patches (Auth & Region)
pwsh ./install-antigravity-patch-windows.ps1

# Option 2: Apply ONLY the region bypass (for regional restrictions)
pwsh ./install-antigravity-patch-windows.ps1 -RegionOnly

# Option 3: Apply ONLY the authorization/proxy fix
pwsh ./install-antigravity-patch-windows.ps1 -AuthOnly
